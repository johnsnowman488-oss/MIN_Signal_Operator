# Experiment 13A-1 — Kernel–SOE Geometry Atlas

## Purpose

12A–12D treated recovery of the original waveform as the main downstream
question. The 13A branch changes the object of study.

The first variant asks:

> **How does controlled kernel geometry change the temporal state/feature
> representation generated by MIN?**

No channel, receiver, AWGN, classifier, predictor, or learned model is used.
The experiment is therefore a forward-representation study.

For a positive exponential kernel family,

\[
K(t)=\sum_{j=1}^{m}a_j e^{-\gamma_j t},
\qquad a_j>0,
\]

define the causal states

\[
q_j(t)=\int_0^t e^{-\gamma_j(t-s)}x(s)\,ds.
\]

The scalar MIN output is

\[
y(t)=\sum_j a_jq_j(t).
\]

The vector

\[
q(t)=[q_1(t),\ldots,q_m(t)]
\]

is treated as a **temporal state/feature space**. The experiment does not
assume that its trajectories form a mathematical manifold.

## Variant grid

The controlled atlas varies:

- BPSK, QPSK, 16-QAM;
- mode count \(m\in\{1,2,4,8,16\}\);
- decay-rate geometry:
  - clustered: rates concentrated near 10 s^-1;
  - logspread: rates logarithmically spaced from 2 to 30 s^-1;
  - wide: rates logarithmically spaced from 0.5 to 100 s^-1;
- positive weight geometry:
  - uniform;
  - slow-dominant;
  - fast-dominant;
- five deterministic seeds.

This gives 45 kernel conditions and 15 signal/seed combinations per condition,
for **675 result rows**.

The clustered family is intentionally close rather than exactly repeated:
it probes redundancy without creating an exactly duplicated state coordinate.

## Discretization

The experiment uses the continuous exponential-state equation over each
sample interval with piecewise-constant input:

\[
q_j[n]
=
e^{-\gamma_j\Delta t}q_j[n-1]
+
\frac{1-e^{-\gamma_j\Delta t}}{\gamma_j}x[n].
\]

This is a state realization of the continuous exponential convolution, not
the normalized finite sampled-kernel implementation used in earlier receiver
experiments. That distinction is intentional: 13A-1 studies the state
representation itself.

The aggregate output remains

\[
y[n]=\sum_j a_jq_j[n].
\]

## Measurements

### State geometry

For the centered state trajectory, the experiment computes the covariance
eigen-spectrum and records:

- participation-ratio effective dimension;
- rank explaining 90% and 99% of variance;
- maximum pairwise state-component collinearity;
- RMS trajectory radius;
- trajectory length;
- total state energy;
- minimum/maximum component energy.

Two coordinate conventions are retained:

1. unweighted \(q_j\);
2. \(\sqrt{a_j}q_j\).

The second is an explicit weighted coordinate convention. It is not declared
intrinsically superior to the first; Euclidean geometry changes under
coordinate scaling.

### Kernel temporal structure

For the aggregate causal impulse response, record:

- sampled L1 and L2 magnitude;
- 50% and 90% cumulative-magnitude times;
- magnitude centroid;
- DC and Nyquist gain;
- sampled frequency dynamic range;
- frequency of maximum sampled response.

### Scalar output

The scalar MIN output is separately characterized by energy, RMS trajectory
length, and its scalar effective dimension.

## Interpretation rules

A larger effective dimension is **not** automatically better.

A larger trajectory length is **not** automatically more informative.

A longer memory time is **not** automatically more useful.

The purpose of the atlas is to determine whether kernel geometry produces
systematic, reproducible changes in the temporal representation that can later
be connected to a task.

The experiment therefore does **not** claim:

- signal preservation;
- invertibility or irreversibility;
- communication advantage;
- classification advantage;
- prediction advantage;
- propagation robustness;
- manifold formation.

Those require later experiments.

## Expected next connection

13A-1 supplies the representation side of

\[
(K,x)\rightarrow q_K(t).
\]

The next experiment can then test whether regions of this kernel geometry
space have different utility for an explicitly defined task:

\[
(K,\mathcal T)\rightarrow U.
\]

That task layer should be introduced only after this atlas is numerically
validated.
