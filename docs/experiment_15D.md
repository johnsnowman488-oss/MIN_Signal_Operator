# Experiment 15D — Equal-budget temporal representation comparison

## Question

Does the 15C advantage of MIN over a single matched one-pole memory persist when competing representations are given the same 16-state budget?

## Representations

- **MIN-16:** process-adapted 16-mode positive exponential dictionary.
- **IIR-logspread-16:** conventional 16 first-order exponential states spanning the same minimum-to-maximum rate range as MIN.
- **Dense-state-16:** an orthogonal similarity transform of the conventional 16-pole bank. This is a coordinate-control, not a distinct kernel family.
- **FIR-16:** a 16-sample finite-history delay line.

All representations receive the same noisy observation and use the same train/test split, PCA sweep, linear readout, processes, SNR levels, scale factors, and seeds.

## What 15D can establish

The primary comparison is representation quality at fixed state dimension. The cost fields record state dimension, stored state values, parameter count, and an implementation-level multiply/add proxy.

A result favoring MIN-16 over IIR-logspread-16 and FIR-16 would support a claim that the *arrangement of temporal modes* matters beyond merely having 16 coordinates.

The dense-state control should match the conventional pole-bank performance up to numerical noise. A discrepancy would indicate an implementation problem rather than a scientific effect.

## What 15D cannot establish

It does not by itself prove universal computational superiority, optimality of the MIN dictionary, or superiority over every possible 16-state state-space model. It is a controlled equal-budget benchmark.

## Expected scale

5 seeds × 4 processes × 6 scale factors × 4 SNR levels × 2 tasks × 4 representations = **3,840 case rows** and **61,440 PCA rows**.

The artifact generated by CI is the authoritative numerical record.
